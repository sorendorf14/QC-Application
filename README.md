QC code package for non-AMRDC including python code and examples of input files. A lot of this code has been altered from the version AMRDC uses to try and be as reproducible and generic for other groups as possible; however, there are aspects of the code, especially in the tall tower versions of the code, that are tailored to AMRDC data and stations that may need to be altered to fit your stations. We have outlined where certain parts need to be changed . 

Tutorials for installation, running the code, and troubleshooting are located in the [wiki](https://github.com/sorendorf14/QC-Application/wiki).


Python code is located in the [code folder](https://github.com/sorendorf14/QC-Application/tree/main/code).

Input files are located in the [input_files folder](https://github.com/sorendorf14/QC-Application/tree/main/input_files)

Separate readme files are in each folder explaining the files within in more detail. 

If you have questions not answered by the wiki or readme files, please contact test-example@wisc.edu. 

Missing data are represented by values of 444.0.
